# Relevant — превью страницы услуг Авито

Статический макет для просмотра и согласования. HTML, CSS, JavaScript и все используемые изображения, видео и шрифты находятся в этом репозитории. Сборка и сервер не требуются.

Форма подготавливает письмо на info@relevant.ru; отправка происходит в почтовом приложении посетителя. Статистика на иллюстрациях имеет условные значения и помечена как пример.

## Публикация

Адрес: https://sermoffice.github.io/relevant-avito-preview/ .

GitHub Settings → Pages → Source: GitHub Actions. Сценарий `.github/workflows/pages.yml` публикует статические файлы при изменениях в `main`; его можно запустить вручную во вкладке Actions.

Все изображения, видео и шрифты сохранены в `assets`. Страница и публикация не зависят от доступности ChatGPT.
